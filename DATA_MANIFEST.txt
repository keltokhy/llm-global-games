DATA MANIFEST — output/
========================

This directory contains the experiment outputs used by
paper/paper.tex ("Speaking in Code: Surveillance and Coordinated
Dissent in a Language-Based Global Game with LLM Agents").  Paper asset lineage is recorded in
paper/asset_manifest.tsv; scripts/make_data.py declares the runnable
targets needed to reproduce missing data.


DIRECTORY STRUCTURE
-------------------
output/
├── <model-slug>/                        Per-model benchmark results
│   ├── experiment_*_summary.csv         Period-level experiment summaries
│   ├── experiment_*_log.json            Agent-level prompts/responses
│   └── manifests/                       Run provenance
├── <experiment-variant>/<model-slug>/   Robustness and mechanism experiments
└── comparison/                          Cross-model summary files


CORE BENCHMARK EXPERIMENTS
--------------------------
Per-model directories contain:
  experiment_pure_summary.csv            Private-signal global game
  experiment_comm_summary.csv            Pre-play network communication
  experiment_scramble_summary.csv        Falsification: briefing permutation
  experiment_flip_summary.csv            Falsification: negated signal direction
  calibrated_params_*.json               Per-model briefing-centering parameters
  calibrated_index.json                  Index of per-model centering parameters
  autocalibrate_history.csv              Centering search history where available
  autocalibrate_final_raw.csv            Raw centering sweep rows where available
  manifests/                             Provenance, including load_calibrated flags

Canonical model roster is defined in analysis/models.py.  Main benchmark
tables use seven models: Mistral Small (primary), Llama 3.3 70B, Qwen3
30B, GPT-OSS 120B, Qwen3 235B, Trinity Large, and MiniMax M2-Her.  Additional
directories may exist for exploratory or archived runs and are excluded
unless referenced by analysis/models.py or paper/asset_manifest.tsv.

Benchmark and mechanism outputs were generated with the per-model
briefing-centering parameters recorded above.  In the checked files, only
cutoff_center differs from the default briefing generator; other generator
settings remain at their default values.

ARCHIVED: INFODESIGN / BAYESIAN PERSUASION OUTPUTS
--------------------------------------------------
Information-design experiments (stability, instability, public-signal,
censorship and channel decomposition) are not used by the current
manuscript and have been moved to _archive/infodesign/.  Code modules
(agent_based_simulation/{infodesign.py,run_infodesign.py}) and the
corresponding figures/tables live there too, intended for a follow-up.
Key archived output families include:
  mistralai--mistral-small-creative-infodesign-comm/
  surveillance-x-censorship/
  bandwidth-005/
  bandwidth-030/
  z-centered/


CSV COLUMN REFERENCE
--------------------
Core pure/communication/scramble/flip summaries:
  country, period, treatment, theta, theta_star, z, benefit,
  n_join, join_fraction, n_valid, n_api_error, n_unparseable,
  join_fraction_valid, api_error_rate, unparseable_rate,
  coup_success, theoretical_attack

For benchmark Part I analyses, analysis/verify_paper_stats.py recomputes
the canonical attack-mass benchmark under B=C=1 and sigma=0.3 from theta,
rather than relying on legacy logged benefit/theoretical_attack columns.
